# Riverside RP Police

Изолированная система полиции для Riverside RP. Она подключается к существующему `job_selector`, но не изменяет его навигацию, деньги, Civil и интерфейс F4 напрямую.

## Установка

В архиве две папки, обе нужно положить в `garrysmod/addons/`:

```text
job_selector/
riverside_police/
```

Старую версию `job_selector` с вшитой полицией нужно заменить этой версией.


Телепорт на полицейскую точку выполняется только после настоящей смерти или принудительного перехода в полицию. Выход из регдолла больше не считается респавном.


Сервер рекурсивно добавляет файлы модели и её материалов через `resource.AddFile`, поэтому наличие модели только на сервере не приводит к фиолетовым текстурам у клиентов. После обновления нужно полностью перезапустить сервер и переподключиться.


Модель устанавливается через стандартный `player_manager`, а не через отдельную загрузку Workshop или принудительную resource-раздачу. Это соответствует способу, которым модель выбирается через C-меню.


После установки модели сбрасываются только bodygroup-слоты. Skin, material, кости и аксессуары не изменяются.


Все bodygroup-слоты сбрасываются в значение `0`, то есть в дефолтное состояние модели, сразу после установки и ещё раз на следующем тике.
